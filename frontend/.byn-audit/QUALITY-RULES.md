# BYN AUDIT QUALITY RULES

1. Do not modify application source code during an audit.
2. Do not fabricate test results.
3. Do not claim a feature works without testing it.
4. Do not claim an API/backend issue is a frontend issue without evidence.
5. Separate bugs from design opinions.
6. Prioritize user impact.
7. Test mobile explicitly.
8. Test core journeys before cosmetic details.
9. Prefer reproducible findings.
10. If something cannot be tested, state why.
11. Preserve evidence where available.
12. Never expose or copy secrets into audit files.
13. Never use production credentials unless explicitly authorized and safely provided.
14. Prefer local/test data for audit execution.
15. Finish with a prioritized remediation plan.
